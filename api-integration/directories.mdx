## Directories

### Get All Directories

Retrieve all directories owned by the authenticated user.

```http
GET /api/directories
```

**Response:**

```json
{
  "data": [
    {
      "id": 1,
      "name": "Tech Startups Directory"
    },
    {
      "id": 2,
      "name": "Design Tools Directory"
    }
  ]
}
```

### Get Directory Languages

A directory's default and extra languages, with each language's home page URL:

```http
GET /api/directories/{directory_id}/languages
```

See [Languages & Translations](/api-integration/languages) for the response and for reading and writing content in each language.
