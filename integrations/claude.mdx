Claude integration lets you use Anthropic's Claude models for all AI content generation in your directory — listing content, SEO titles and meta descriptions, category and directory page content, and AI URL extraction on public submissions. You bring your own Anthropic API key and pay Anthropic directly for what you use.

## Setup

To enable Claude integration:

1. Create an [Anthropic account](https://console.anthropic.com)
2. Get your API key from the Claude Console (API Keys section)
3. Go to your directory settings
4. Navigate to "Integrations"
5. Paste your API key in the "Claude API (Anthropic)" section
6. Pick a model and save changes

## Choosing a model

| Model | Best for |
| --- | --- |
| **Claude Opus 4.8** | The most capable model — highest quality content |
| **Claude Sonnet 5** | The best balance of quality, speed and cost |
| **Claude Haiku 4.5** | The fastest and cheapest — great for bulk generation |

You can change the model at any time from the Integrations page.

## Features

With Claude connected, every "Generate with AI" action in your panel uses Claude:

- **Generate SEO with AI** — titles and meta descriptions for listings, categories, and blog posts
- **Listing content generation** — single listings or bulk generation for up to 100 listings at once
- **Category and directory page content** — engaging intro content written from your titles and descriptions
- **AI URL extraction** — pre-fill public submission forms from a pasted website URL

## Using Claude and OpenAI together

You can keep both Claude and OpenAI connected at the same time. When both are set up, an **Active AI Provider** selector appears at the top of the Integrations page — choose which provider handles AI generation, and switch whenever you like (for example, when one account runs out of credits).

If only one provider is connected, it is used automatically and no selector is shown.

<Note>
API usage is billed directly by Anthropic based on your account's pricing. Your API key is stored encrypted.
</Note>
